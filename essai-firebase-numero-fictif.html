Test de connexion — sans SMS

Mode fictif Firebase • zéro message envoyé

Mode d'essai uniquement. Utilise un numéro fictif enregistré au préalable dans Firebase Authentication → Téléphone → Numéros de téléphone pour les tests. Le code ne sera envoyé ni par WhatsApp ni par SMS : c'est celui défini dans Firebase.

Première connexion

Ne saisis pas ton véritable numéro. Utilise le numéro fictif et le code à six chiffres que tu viens d'enregistrer dans Firebase.

Avant de cliquer : dans Firebase → Authentication → Méthode de connexion → Téléphone, ouvre « Numéros de téléphone pour les tests » et vérifie que le numéro fictif est bien dans la liste avec son code de 6 chiffres. Activer le fournisseur Téléphone ne suffit pas pour ce mode d'essai.

✅ Connexion de test réussie

Firebase reconnaît le numéro fictif et la session a été conservée sur cet appareil.

Ferme cette page puis rouvre-la : si la session est toujours valide, tu arriveras directement ici, sans code.

Prêt : aucun SMS réel ne sera envoyé depuis cette page.

Test d'authentification exclusivement. Aucun dossier d'enfant, aucune donnée V3 et aucun accès parent réel sur cette page. Le numéro fictif crée néanmoins un compte Firebase Auth de test : après validation du pilote, supprimer ce compte et le numéro fictif de la configuration Firebase.
