Diffusion des accès Parents — méthode WhatsApp

Le lien est identique pour toutes les familles

La Direction n'a aucun code PIN ni lien individuel à préparer. Chaque famille utilise le numéro de téléphone qu'elle a déjà communiqué à G10, puis reçoit un code WhatsApp généré par l'application.

Attention — avant toute diffusion : l'envoi automatique WhatsApp et le service Firebase Parents doivent être activés et testés avec une vraie famille. À ce stade, ne transmets pas encore le lien à tous les abonnés.

Après validation du pilote : procédure de l'équipe

1. Vérifier le contact parental dans G10 V3

Le numéro WhatsApp du parent doit figurer dans son dossier abonné existant. Aucun numéro d'urgence utilisé par défaut.

2. Envoyer le lien commun par WhatsApp

L'équipe G10 envoie le message ci-dessous, sans PIN ni mot de passe.

3. Laisser le parent se connecter

Il indique son numéro (+241), reçoit son code WhatsApp, le saisit une fois et retrouve automatiquement ses enfants. Sa session reste ouverte sur cet appareil.

Les comptes Direction et Logistique sont distincts des comptes Parents. Aucun dossier familial ne figure dans le HTML public de cette page.
